# Dental Lab Manager

Готовая стартовая веб-программа для зуботехнической лаборатории.

## Что уже есть

- Один аккаунт для телефона и ПК.
- Облачная синхронизация через Supabase.
- Локальный режим без регистрации.
- Прайс в USD, который заполняет владелец лаборатории.
- Создание заказов.
- Ввод: «5 лсп металл, 3 циркона, 2 металлокерамики».
- Автоматический расчёт количества × цена.
- USD → UZS по заданному курсу.
- Статусы «Оплачено / Не оплачено».
- Клиенты/врачи.
- Дашборд: заказы, выручка, долги.
- Копирование готового сообщения клиенту.
- Голосовой ввод там, где браузер поддерживает SpeechRecognition.
- Резервная копия JSON.
- PWA: можно установить сайт как приложение на Android/Chrome.

## Как включить синхронизацию

1. Создай аккаунт на Supabase.
2. Создай новый проект.
3. Открой SQL Editor.
4. Выполни `supabase.sql`.
5. В настройках Authentication при необходимости настрой подтверждение email.
6. В Project Settings → API возьми Project URL и `anon`/`public` key.
7. Открой приложение и вставь их в поля подключения.
8. Создай аккаунт.
9. На телефоне и ПК войди под одним email/паролем.

## Публикация

Самый простой вариант — разместить папку на любом статическом хостинге (например, GitHub Pages, Cloudflare Pages, Netlify или другом). После публикации один и тот же адрес открывается и на телефоне, и на ПК.

## Важная безопасность

- Никогда не вставляй в браузер Supabase `service_role` key.
- В приложении используется только публичный `anon` key + Row Level Security.
- Если добавишь настоящий платный/внешний AI API, ключ нельзя хранить в `app.js`; для него нужен серверный proxy/Edge Function.

## Как добавить настоящий AI

Текущая версия имеет «умный» разбор текста без платного AI API. Для настоящего ИИ можно добавить Edge Function, которая получает фразу пользователя, превращает её в структурированный JSON позиций и возвращает его приложению. Это позволит понимать более свободную речь и ошибки в названиях.
